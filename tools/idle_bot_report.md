# 托管五项增强交付报告 · bot v2.2 → v2.3（2026-09-19）

依据 2026-09-19 四章漏斗校准实测（N=300：死亡几乎全部在章节中段、章内强度小曲线 CH_INTRA、
r40 起幸存者 HP 常驻 15-16/40、守关条件通过率 87-93%、syn_test 比主托管强 15-25pp），
按任务书实现五项托管增强并重校漏斗。**方法升级**：sim.js 加 SEED 确定性补丁（mulberry32，
游戏代码 eval 前替换 Math.random）；决策一律三种子（SEED=42/43/44 各 N=100）配对合并——
单种子聚合会被「顺序跑局共享 RNG 流 + 蝴蝶发散」放大成 ±10pp 假信号（本轮实测两次踩中）。
