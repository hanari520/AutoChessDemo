多多自走棋 完整数值设计文档（官方底层数值&规则全集）
文档前言
本文档整合多多自走棋全局对局规则、经济数值、战斗数值、蓝量技能系统、星级成长、羁绊机制、伤害抗性、控制规则所有底层设计，为游戏复盘、玩法拆解、同类自走棋对标、数值复刻提供完整依据。
核心设计理念：血量、经济、战力三维等价互换；统一阈值降低认知成本；利息/连胜/连败三重经济制衡；蓝量统一标准化，通过回蓝速率区分棋子特性；数值随星级线性放大，机制不随星级变更。
全局固定常量（全对局通用）
对局人数：8人
单局金币上限：100
利息上限：5金币/回合
连赢/连输奖励上限：3金币/回合
棋子蓝量上限：固定100点（全棋子统一）
战斗内所有CD、蓝量、临时buff、debuff 不跨回合保留
第一章 核心经济系统数值设计
1.1 基础回合收入
前期线性递增，中期锁死上限，压缩后期经济差距来源，倒逼战力博弈
第1回合：1金币
第2回合：2金币
第3回合：3金币
第4回合：4金币
第5回合：5金币
第6回合及以后：固定5金币/回合
1.2 利息系统（核心锚点机制）
结算规则：回合开始前，按当前持有金币向下取整10%，存在硬性上限
10金 → 1利息
20金 → 2利息
30金 → 3利息
40金 → 4利息
50～100金 → 固定5利息（利息封顶阈值）
关键时序规则：战斗结束可自由买卖棋子调整存款，调整后的金额参与下回合利息结算，是高阶运营核心。
1.3 胜负&连胜/连败经济奖励
1.3.1 单场胜负奖励
玩家对战胜利：+1金币；对战失败/平局：无奖励；野怪回合：无胜负奖励，不刷新连段计数。
1.3.2 连段奖励（上下限封顶）
3连赢/3连输：+1金币
5连赢/5连输：+2金币
7连及以上连赢/连输：+3金币（封顶）
重置规则：平局、被玩家打断连段清零；野怪回合保留连段。
理论单回合最大经济收益：5基础+5利息+1胜利+3连段 = 14金币
1.4 金币消耗体系（固定定价）
商店刷新：2金币/次，每回合免费自动刷新1次，锁店无消耗
人口升级：5金币=4点棋手经验；每回合自然保底+1经验
棋子购买：1/2/3/4/5费对应固定售价，取自全局共享卡池
1.5 棋子出售规则
1星棋子：全额原价返还金币
高费2星、所有3星棋子：出售亏损，禁止理财套利
特殊机制：德鲁伊种族可低成本合成2星，存在专属小额理财收益
第二章 技能与蓝量系统数值设计（核心战斗驱动）
2.1 技能分类与基础规则
2.1.1 主动技能（大招）
固定消耗100蓝释放，释放后蓝条清零，进入战斗内CD，CD不跨回合；需合法目标、无强控制状态方可释放。部分引导型大招可被眩晕、变形、石化打断，打断不返还蓝量。
2.1.2 被动技能
无蓝量消耗，战斗常驻生效；不吃沉默效果，仅变形、石化可禁用；星级提升仅放大数值，不改变机制。
2.1.3 羁绊技能
全队全局buff/debuff，可直接改写战斗、回蓝、技能生态（例：3龙开局满蓝、3法师减魔抗）。
2.2 统一蓝量&回蓝数值公式
全局蓝上限100，开局清零、回合结束清空，无跨回合留存。
2.2.1 攻击回蓝（按最终实际伤害结算）
法师/萨满/术士职业：min(伤害÷2.5，20)，单次最大20蓝
其余所有职业：min(伤害÷2.5，10)，单次最大10蓝
2.2.2 受击回蓝（挨打随机回蓝）
回蓝区间：[min(伤害÷10,25) ~ min(伤害÷5,50)]
特殊规则：被召唤物攻击无法回蓝。
2.2.3 特殊回蓝机制
冰女光环：友方固定间隔回蓝，多光环不叠加、取最高值
3龙羁绊：所有龙族棋子战斗开局直接100满蓝，无攒蓝过程
装备修正：回蓝类装备提供百分比乘区，放大所有回蓝收益
2.3 大招释放优先级规则
蓝量达标后，严格按照棋盘从左到右、从上到下顺序依次释放，非先满先放；蓝量可溢出，但释放固定消耗100点，溢出部分作废。
第三章 战斗数值体系（伤害、抗性、控制）
3.1 三类伤害机制
物理伤害：受护甲减免，可被闪避，普攻与物理技能通用
魔法伤害：受魔法抗性减免，法师技能核心伤害类型
纯粹伤害：无视所有护甲、魔抗，直接结算血量，仅少数大招/羁绊拥有
3.2 护甲/魔抗 官方精准减免计算公式（战斗数值核心闭环）
3.2.1 物理护甲减免公式（数值型线性曲线）
多多自走棋物理护甲为固定数值结算，所有护甲加成、减益全部线性叠加后统一计算，支持正负护甲阈值判定。
最终物理伤害减免率：减免率 = (0.052 × 总护甲) ÷ (0.9 + 0.048 × |总护甲|)
最终承伤倍率：承伤倍率 = 1 - 物理减免率
核心规则说明
总护甲为所有来源线性叠加：棋子基础护甲 + 装备护甲 + 羁绊护甲 + 技能增减护甲
护甲为正数：提供物理伤害减免，收益边际递减，护甲越高提升收益越低
护甲为负数：触发物理伤害加深，无收益递减，负护甲越低承伤越高
理论上限：护甲225点时物理减免趋近100%，达成物理伤害完全免疫
常用护甲阈值速算参考
20护甲 ≈ 57%物理减免
45护甲（单件大件满值）≈ 78%物理减免
50护甲 ≈ 80%物理减免（收益拐点，后续提升微乎其微）
-5护甲 ≈ 20%物理伤害加深
3.2.2 魔法抗性减免公式（百分比乘算）
魔法抗性与护甲计算逻辑完全不同，采用多段百分比乘算叠加，所有魔抗来源独立生效、互不稀释。
最终魔法承伤倍率：承伤倍率 = (1-a) × (1-b) × (1-c) × ……
最终魔法减免率：减免率 = 1 - 最终承伤倍率
参数说明：a、b、c为所有魔抗来源的百分比数值（基础魔抗、装备魔抗、羁绊魔抗、技能魔抗增减），增益为正、减益为负。
核心规则说明
魔抗无边际递减：多件魔抗装备、多重羁绊可以无限叠加，趋近100%魔法免疫
负魔抗效果极强：敌方降低魔抗的debuff会直接放大法系伤害，无衰减限制
数值独立结算：每件魔抗装备、每个羁绊效果单独乘算，收益稳定不稀释
实例演算：棋子基础0魔抗 + 深渊魔抗甲45%魔抗 + 羁绊20%魔抗
承伤倍率 = (1-0.45)×(1-0.2) = 0.44
最终魔法减免 = 56%，远高于单装备数值，体现魔抗叠加优势
3.2.3 法穿/穿透结算优先级规则
穿透效果为伤害结算前预处理，优先级高于所有减免计算，是法系克制肉坦的核心机制。
魔法穿透：按百分比直接削减敌方总魔抗，再进行魔抗减免乘算
穿透无上限、无下限：可将敌方魔抗压至负数，触发魔法伤害加深
多法穿装备叠加：多件虚空之眼为百分比乘区叠加，大幅压低高额魔抗目标抗性
3.2.4 物理穿透完整结算公式（新增闭环）
多多自走棋物理穿透为百分比穿透机制，结算逻辑与魔法穿透对齐，仅作用于敌方总护甲，不改变护甲基础计算公式，无固定穿透、无穿透上限。
物理穿透结算流程
最终有效护甲 = 敌方总护甲 × (1 - 物理穿透总占比)
将计算后的最终有效护甲代入官方护甲减免公式，结算最终物理伤害。
多物穿叠加规则：多件物理穿透装备/技能为数值加法叠加，无稀释、无乘区衰减，可直接压低敌方高额护甲，轻松突破物理防御阈值。
特殊阈值规则：物理穿透可将敌方有效护甲压制为负数，触发物理伤害加深效果，加深幅度遵循护甲负数值公式，无上限约束。
3.2.5 双穿透统一结算优先级（物穿+法穿）
游戏内穿透效果拥有最高结算优先级，固定顺序全局统一，无特例：
第一步：计算所有穿透效果（物穿/法穿），压低敌方对应抗性
第二步：代入抗性减免公式，计算伤害减免/加深倍率
第三步：叠加增伤、减伤、羁绊修正等所有乘区，结算最终伤害
核心结论：穿透是伤害前置破防手段，优先级高于一切减免、增伤机制，是突破肉坦阵容的核心属性。
3.2.6 全局伤害保底机制（补全数值兜底规则）
为杜绝零伤害、刮痧无效输出，游戏设置统一伤害保底阈值，所有伤害类型通用。
任意伤害结算后，最低强制造成5%保底伤害
该规则适配物理、魔法、所有技能伤害，纯粹伤害不触发保底（可全额无损）
即便敌方100%抗性、极致防御堆叠，依旧会受到保底伤害，杜绝完全无敌机制，保证对局博弈性
3.2.7 抗性系统核心制衡逻辑
物理护甲：数值线性叠加、收益边际递减，堆护甲有上限，避免物理系完全无敌
魔法魔抗：百分比乘算、无收益上限，堆魔抗无天花板，法系克制依赖高额护甲的纯坦阵容
正负抗性不对称：负护甲加深幅度温和，负魔抗伤害增幅极强，天然制衡纯肉法系坦度
双穿透制衡防御：物理/法术穿透可无视高额防御堆叠，打破纯肉躺平体系，强制战力博弈
保底伤害兜底：杜绝数值锁死无敌，保证所有阵容存在反制空间
物理护甲：数值线性叠加、收益边际递减，堆护甲有上限，避免物理系完全无敌
魔法魔抗：百分比乘算、无收益上限，堆魔抗无天花板，法系克制依赖高额护甲的纯坦阵容
正负抗性不对称：负护甲加深幅度温和，负魔抗伤害增幅极强，天然制衡纯肉法系坦度

5.4 抽卡底层机制细则
独立卡槽判定：商店5个卡槽每格独立概率判定，不存在抽中一张高费卡就降低其他卡槽高费概率的机制。
卡池为空兜底：对应费用卡池棋子被抽空时，该卡槽会自动跳过该费段，随机抽取剩余可抽费用棋子。
无概率浮动修正：无隐藏保底、无概率递增、无连败/连胜抽卡加成，概率全程固定。
锁店机制不改变概率：锁定商店仅保留当前棋子，下次刷新依旧遵循当前人口概率。

第六章 对局完整时序流程（数值生效关键逻辑）
6.1 回合准备阶段
布阵、买卖棋子、锁商店、调整装备，无任何战斗数值结算。
6.2 战斗阶段
战斗初始化：全员蓝量清零、临时buff/debuff清空
开局羁绊触发：萨满变形、3龙满蓝等开局效果优先生效
棋子寻路普攻，通过攻击/受击持续回蓝
满蓝棋子按棋盘顺序依次开大，触发技能CD与控制效果
战斗直至一方全员淘汰，结束对局
6.3 回合结算阶段（核心运营窗口）
结算战斗胜负，发放胜利金币，更新连胜/连败计数
玩家可自由买卖棋子、调整手持金币金额
下一回合启动：结算利息、发放基础收入、发放连段奖励
第七章 系统设计核心权衡与制衡逻辑
7.1 经济制衡设计
50金利息封顶：杜绝大额存款无限滚雪球，强制玩家后期花钱提战力
连胜/连败双奖励：兜底烂分玩家、奖励强势玩家，惩罚摇摆混子打法
基础收入中期锁死：经济差距仅靠运营细节拉开，杜绝纯数值碾压
7.2 技能战斗制衡设计
统一100蓝上限：降低认知成本，靠回蓝速率区分棋子定位（前排快控、后排慢爆发）
强控制可打断引导技能：给弱势阵容反制上限，克制无脑法系输出
羁绊改写核心机制：让阵容强度不依赖单棋子星级，丰富战术体系
第八章 与主流自走棋（云顶/金铲铲）核心数值差异
蓝量机制：多多全棋子统一100蓝；云顶各棋子蓝条阈值不同
蓝量留存：多多蓝量、CD不跨回合；云顶可保留部分溢出蓝与CD状态
羁绊机制：多多存在3龙开局满蓝这种改写底层循环的羁绊；云顶无同类机制
经济机制：多多无选秀回合，无免费棋子/装备获取渠道，经济更依赖纯运营
被动规则：多多被动不吃沉默；云顶沉默可禁用大量被动效果

9.4 装备核心生效规则
9.4.1 叠加规则
相同属性装备可叠加数值收益；
同类唯一机制装备不叠加，仅生效最高值效果；
回蓝百分比乘区可叠加，但单次回蓝硬上限不突破（系统最高阈值锁死）。
9.4.2 失效与刷新规则
所有装备属性、战斗buff、debuff效果仅单场战斗生效；
回合结束后临时效果清空，装备本体保留，可继续调整佩戴；
装备不会随棋子出售、替换消失，可无限流转复用。
9.5 装备系统设计制衡思想
无随机性合成：固定二合一路线，运营可控，避免赌装备崩盘，降低对局恶意随机度。
节奏型装备制衡数值装备：纯属性装备拉高战力，回蓝/功能装备改变打法，让低星级阵容可通过装备节奏反制高星碾压。
不颠覆底层机制：所有装备均是「放大原有特性」，不会让坦克变成输出、法师变成前排，保证棋子定位稳定。
无专属绑定装备：装备通用流转，资源利用率最大化，贴合自走棋灵活变阵的核心玩法。
9.6 与云顶/金铲铲装备体系核心差异
合成机制：多多装备无随机、无分支、固定二合一；云顶存在散件混搭多合成路线。
获取渠道：多多仅野怪掉落，无选秀装备获取；云顶核心装备来源为选秀。
机制强度：多多装备不改变技能机制，仅增幅数值与节奏；云顶部分装备可改写棋子核心玩法。
回蓝体系：多多装备为回蓝百分比乘区，体系严谨可控；云顶回蓝装备无统一公式约束。
