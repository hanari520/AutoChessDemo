## Phase 3 · ④ 血量相对线（防御姿态）（2026-09-19）

- **改动**（bot_strategy.js）：章首 prep（(S.round-1)%chLen()===0）判定 `S.botDef = hp < hpMax()*0.6`
  （bloodpact 下限 25→15 自动适配）；姿态影响三处——装备步防御装只补 JOB_FRONT（前排槽满则
  轮换背包队尾，不散装给后排）；换血步跳过 JOB_FRONT（板凳与场上两处，不卖前排）；botAugScore
  防御系（startshield/regen/ar/mr/hp）+15（与 hp≤12 sustain 叠加≈加倍）。crisis/urgent 绝对线
  与 botEconMode 不受姿态影响。
- **方法教训**：单种子 SEED=42 N=100 显示 +4/+5/+12/+13pp，非种子 N=100 却 -3/-6/-5pp——
  sim 顺序跑局共享同一条 RNG 流，第一局行为分叉后后面所有局等于重抽样，单种子聚合会放大
  蝴蝶效应。**决策必须多种子配对合并**。
- **数据（SEED=42/43/44 各 N=100 配对，合并≈N=300）**：before（=Phase2 后）均值
  83.7/69.3/58.3/46.0 → after（+④）均值 **81.7/72.3/64.7/54.0**：ch1 -2.0（噪声内）、
  ch2 +3.0、ch3 **+6.3**、ch4 **+8.0**——章节中后段存活显著改善（chReached ch4 52→71@s42）。
- **结论**：采纳 ④。ch3/4 提升超出 ±4pp 噪声带；漏斗整体上移留待 Phase 6 加难度回锚。

## Phase 5 · ⑤ 经验加速 1→2 次/回合 A/B → **回退**（2026-09-19）

- **实验组**：升级步 gold≥50 时每回合最多买 2 脚（5金+4经验；「升一级就停」改为升完当级继续买
  下一级的第 2 脚；每脚仍保 50 利息地板）。
- **数据（SEED=42/43/44 各 N=100 配对）**：Phase4 均值 83.0/71.7/63.3/55.0 → 实验组均值
  **82.0/67.7/60.0/47.7**（ch2 -4.0 / ch3 -3.3 / ch4 -7.3，ch2-4 均值 **-4.9pp**）；ch1 -1.0 未超 3pp。
  逐种子：s42 -10/-6/-12/-11、s43 0/-7/-7/-17、s44 +7/+1/+9/+6（分歧大但合并显著为负）。
- **归因**：gold≥60 的溢出原本流向 chase/healthy 搜牌（板面战力），2 脚经验把它抽去填
  6→7=32xp 经验墙——人口上去了、场上质量掉了，途中流血反而加重。与 syn_test 锁羁仪器
  「持续买经验滚人口更强」的结论相反，因为锁羁仪器的经验来自「存满 50 只花溢出」纪律，
  而非加倍抽搜牌预算。
- **结论**：未达「ch2-4 综合 ≥+3pp」采纳线，**回退**（升级步恢复升一级就停；代码注释留档）。
  回退后 SEED=42 N=100 与 Phase4 输出逐字节一致（REVERT-CLEAN）。
- **BOT_VER 升 v2.3** + index.html `bot_strategy.js?v=3` → `?v=4`（sw 对该文件网络优先，无需升 CACHE）。
- **②b 开启态实测（TB=1 SEED=42 N=100）**：90/76/75/62 → 86/61/55/47（ch2 -15 / ch3 -20 / ch4 -15pp）
  ——章末低血常驻触发下每章 3-4 回合×25💰 齐射抽干经济，伤害一次性收益远不抵复利损失。
  **默认关有数据背书**；用户试玩若要开，建议只在 crisis 或仅守关回合买（当前实现按约定保持原样）。
