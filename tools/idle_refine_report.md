## 六、声音系统（二.5，Web Audio 程序化合成，当前零音频代码从零建）

- 单一 `sfx(key)` 入口；27 条音效定义 + 8 组技能音色映射（SFX_SKILL）；振荡器琶音+噪声层+增益包络，单文件零外部资源。
- 性能纪律：同 key ≥100ms 限流、全局并发 ≤8 voices（实测峰值 6~8）、音高 ±5% 随机微调、分类音量总线 ui .5 / battle .42 / global .6。
- 静默降级：无 AudioContext（sim DOM 桩/无头）no-op；自动播放策略：pointerdown/keydown resume，此前静默不报错；sim 3 局冒烟零报错。
