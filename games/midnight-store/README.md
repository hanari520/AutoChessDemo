# 下播后的便利店

《下播后的便利店》是一段七个夜晚的单人经营故事。每晚先补货，再迎接三个来客时段里的岁己、栞栞与街坊故事；你可以按已经出现的线索推荐商品，也可以随时递上一杯热水、认真听她说完。没有限时操作，也不显示好感数值。

## 游玩

从游戏馆进入本页，或在本机静态服务器中打开 `games/midnight-store/index.html`。开店前可查看商品进价、售价、温度、口味、提神、货架类型和鲜食保质说明；每晚最多备三种商品，每种最多四份。退回某种商品的最后一份后，可以换进另一种。空手开店也能完成故事。

字号设置会保存在本机。完成的夜晚会进入故事相册，可回看对话，或独立重演该夜；相册回看不会改变主档，也不会再次登记纪念物。

## 进度与恢复

游戏使用游戏馆共享的 IndexedDB 档案格式，并在每个经营动作后自动保存。导出会生成可再次导入的 JSON 档案；导入前会检查游戏 ID、档案结构和游戏状态。遇到损坏或较新版本的档案时，游戏会保留原档供导出，并要求明确选择有效档案恢复。若浏览器无法使用本地存储，当前页面仍可继续游玩和导出内存中的进度，但不会登记纪念物。

## 文件

- `content.mjs`：商品、顾客、场景和结局文本。
- `core.mjs`：经营规则、分支状态、账本和夜晚回放。
- `app.mjs`、`style.css`：界面、无障碍控制和本地存档接入。
- `../../assets/game-library/midnight-store/store-v1.webp`：便利店室内场景图；生成来源与版本记录见同目录 `manifest.json`。

此作是虚构故事。角色分支记录的是倾听、记住偏好和兑现约定等具体行为。
