# 星渊手记 · 五人远征 RPG

第一章的即时自动战斗原型，采用五人编队、前后排、自动普攻和手动必杀的玩法。直接访问 `index.html`，或在 `autochess` 目录运行 `python -m http.server 8765` 后打开 `http://localhost:8765/rpg/`。

## 第一章：星灯远征

从 50 位角色中选择五人，依次通过四个普通节点、营地休整和章节首领战。角色会自动普攻并积攒 TP；玩家选择攻击目标，在能量蓄满时点击角色头像释放必杀。每次胜利后可选一项队伍祝福，通关会累计星屑并提升本次队伍的羁绊等级。

浏览器本地保存星屑、通关次数、最远节点、角色羁绊和上次编队。清除站点数据中的 `astral_princess_rpg_v1` 可重置。旧版自由移动 demo 保存在 `action.html`。

角色立绘、必杀技名称和技能类型读取自项目现有的 50 人资源清单。常规敌人当前使用代码绘制的独立形象；敌人 AI 生图服务本轮连接失败，后续可替换为正式透明 PNG 素材。
