# 每日挑战诅咒 v2：四章 100 回合

每日挑战固定四章，每章 25 回合，守关在第 **25、50、75、100** 回合。每天一条诅咒，同日同种子且近 10 日不重复。每日规则使用独立 `dc_*` ID 与 `dailyCurse` 存档字段；旧 `curses` 与 `cursesData` 只属于自定义诅咒。旧每日存档缺少 `dailyCurse` 时，按旧 ID 恢复，不重新解释。

`tools/daily-curses.js` 是单一事实来源：`CATALOG` 给展示文案，`modifiers` 给计算与预览数值，`transition` 给一次性补偿。由日期与固定候选池选取单位、装备、封印目标，不消耗商店/战斗随机数。模块给选择项 `options` 和确定性默认 `key`；托管和自动开战使用默认项，不阻塞回合。

## 生命周期与存档

开局调用 `create(seed)`，接着调用 `transition(state,'start',{round:1,units:UNITS})` 与 `transition(state,'roundStart',{round:1,gold,synergies})`。每轮商店自动刷新前调用 `roundStart`；每次**成功的主动**刷新后调用 `refresh`；每场战斗结算调用 `result`，传入 `won/ordinary/creep/boss`。宿主按 `effects` 顺序兑现并保存返回的 `state`。`done` 保证 start、roundStart、result 同回合只发一次。定向单位若无可用棋子或板凳满，给 3 金替代。

`restore(saved,seed)` 只接受版本、日期种子和确定性规则 ID 匹配的状态，否则返回 `null`。旧档无 `dailyCurse` 不调用 `restore`。未来新规则版本须设生效日期，保留历史日期使用的版本，排行榜按日期和规则版本区分。

## 验收

- 逐条固定种子重放第 1/25/26/50/51/75/76/100 回合，比较效果、预览、存档恢复和战报。
- 重复同一事件不重复发奖励；检查 5 回合赏金、封印预告、债务和免费刷新边界。
- 失败战、野怪战不领取普通战赏金；免费机会不能结转；任何补偿不得因满背包而消失。
- 不同种子托管覆盖四章关底，检查卡住、无限资源、负金币、过期补偿和守关胜负。
