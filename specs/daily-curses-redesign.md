# 诅咒规则 v3：每日与自定义共用 12 条

每日挑战从固定池按日期选择一条，同一天规则一致，近 10 天不重复。自定义诅咒只能选择一条，也可以不选。两种模式都采用 4 章，每章 25 回合；第 25、50、75 回合守关后选择增强，第 100 回合终局。

| 诅咒 | 限制 | 补偿 | 玩家额外操作 |
|---|---|---|---|
| 裂隙地带 | 每章我方半区固定 4 个裂隙格，站位者最大生命 -15% | 站位者伤害 +15% | 每章可调整一次 |
| 密阵反噬 | 任意 2×2 区域至少 3 名友军时，该区域棋子攻击速度 -15% | 未触发时全队攻击速度 +5% | 阵型成形后可保持 |
| 侧翼风暴 | 最左、最右列友军受到伤害 +20% | 站位者造成伤害 +15% | 按阵容决定占边 |
| 后排暴露 | 最后一行友军受到伤害 +20% | 前两行友军减伤 8% | 按阵容决定前后排 |
| 羁绊偏科 | 每章指定一项职业或阵营羁绊，门槛 +1 | 每章获得一名具有该羁绊的 2 费棋子，无法入队时给 3 金 | 每章一次 |
| 经济封锁 | 商店 4 格，利息上限 2 金 | 每回合首次主动刷新免费；普通战胜利 +1 金 | 刷新可选 |
| 定额成长 | 不能买经验；每章最后 5 回合敌方攻血 +10% | 每回合自然经验 +3；开局 1 张升星券 | 无 |
| 血债 | 生命上限 32；每 5 回合支付 3 金，不足失去 2 生命 | 开局 +10 金 | 自动结算 |
| 迷雾军情 | 隐藏敌方具体棋子和站位，仍显示人数、费用、羁绊 | 每章获得一件基础装备 | 无 |
| 脆晶军团 | 己方最大生命 -20% | 己方攻击 +20%；每章获得护甲 | 无 |
| 枯潮 | 己方主动技能耗蓝 50→70 | 技能直接伤害与治疗 +20%；每章 +4 金 | 无 |
| 重甲入侵 | 敌方最大生命与攻击 +10% | 每个 5 回合区间首次普通战胜利 +4 金 | 自动结算 |

棋盘诅咒按开战时起始站位计算。裂隙格由日期种子和章节号确定，不消耗商店或战斗随机数；整章保持不变。受影响格在备战棋盘上标出。羁绊偏科目标也在每章开始固定并公告。

规则状态使用 `DailyCurses.VERSION=3`。每日存档与榜单按 v3 隔离；旧每日存档不会被新规则重新解释。旧自定义存档保留旧规则继续运行，新开局列表只显示本页的 12 条。自定义单选诅咒局不进入普通榜。

验证入口：`node --test tools/daily-curses.test.js tools/daily100_backend.test.js`、`DAILY_CAMPAIGN_TEST=1 node tools/sim.js`、`python tools/daily100_test.py`。
