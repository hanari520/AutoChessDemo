# 八人联机与经典挑战界面、战斗表现核对（2026-09-30）

本轮以经典挑战为视觉和交互参照，保留联机模式的八席、共享卡池和服务端确定性结算规则。

## 已补齐

- 顶部等级经验进度条，以及备战和战斗期间可点击的棋子详情。详情显示生命、攻击、攻速、射程、护甲、魔抗、法力、技能和装备；战斗属性取服务端开战快照并随事件更新生命、法力和护盾。
- 阵容羁绊档位、装备说明，以及桌面和窄屏下的棋盘、备战席、商店、战况排列。
- 回放保留棋子节点并逐事件更新位置，显示立绘、血蓝条、伤害数字、攻击、受击、施法、跳跃、治疗、护盾和死亡反馈。施法和技能命中读取经典模式已有的 50 枚棋子图腾、颜色和特效图。完整传输服务端战斗事件，长战斗不截断事件尾部。
- 对照经典模式修正刺客开场跳后排、被控制时不跳、突进技能真实落位，以及最近目标被堵时改选其他可达目标；行动依照服务端 8×8 寻路事件逐格播放。
- 观战切换双方时重建正确视角；毒伤、烧蓝、破盾和装备烧蓝事件携带战后状态，让回放血蓝条与护盾同步。

## 共用经典战斗表现（本轮续作）

- 将经典模式原有的技能动作、技能弹道、斩击、区域波纹、护盾冲击、图腾与普攻命中特效抽到 `tools/battle-presentation.js`；动作与特效 CSS 同步抽到 `tools/battle-presentation.css`。经典页面通过包装函数调用同一实现，联机通过服务端实际事件与目标驱动，视觉层不计算伤害。
- 50 枚棋子的动作表与签名旋转、大小、时长参数共用。普通移动、攻击冲刺、受击和死亡使用经典 CSS；联机保留自己的坐标容器。
- 战斗阶段默认采用四场战斗中最长时长加 1 秒，最低 8 秒；各场按实际时间戳播放，短战斗先结束。计算耗时不挤占动画窗口。`ONLINE_FAST` 仅保留本地与自动测试用的加速行为。
- 增加服务端控制、增益、减益状态快照与有效攻防属性，棋盘显示状态，详情显示护盾和累计伤害；增加我方伤害及治疗统计。恢复会话静默追赶历史事件，切换场次清理旧特效与计时器。
- 页面与共享模块缓存升至 v104。

## 经典模块分布与主题（本轮续作）

- 桌面按经典实际布局重排：左侧详情和羁绊，中央棋盘及下方备战席，右侧战斗统计、装备、战报，底部左侧经验操作及中央商店。八人血条放在棋盘上方；保留原有模块 ID 和事件绑定。恢复战报标题节点，避免重排后更新中断；先将容器挂回页面再移动选择栏，避免空节点被当成文本插入。
- 手机按经典方式通过面板入口展示详情、羁绊、装备与战报，关闭及切换后恢复原位置。经验区域适配窄屏，备战席与棋盘不重叠。
- 经典与联机共用血蓝条、队伍标记和战斗立绘样式；真实浏览器比较浅色/深色、我方/敌方四种组合的计算样式，全部一致。战斗不显示名字和星级。
- 联机沿用经典 `vc_theme` 存储偏好，支持浅色/深色切换、刷新保留及跨页面共享。经典页面在 1440×900 下的棋盘、备战席与侧栏几何回归保持不变。

## 性能实测（v106）

本机 Windows / Node v24.18.0；每类预热 10 个房间，测 100 个房间。每房计算四场战斗并编码八份完整四场观战记录，使用 `node tools/online-battle-benchmark.mjs` 可重测。

| 每方阵容 | 四场平均耗时 | p95 | 最大值 |
| --- | ---: | ---: | ---: |
| 3 枚一星 | 14.36 ms | 22.09 ms | 25.10 ms |
| 11 枚一星 | 88.15 ms | 116.44 ms | 135.81 ms |
| 11 枚三星、装备 | 94.55 ms | 132.69 ms | 141.60 ms |

新增真实羁绊和四场公开观战后，旧版本的测量不能代表当前负载。数据含编码，不含网络传输，不能视为线上并发容量保证；服务仍是单进程内存状态。
