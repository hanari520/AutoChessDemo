# 全项目 AI 美术生成与替换方案

## 授权与范围

用户已于 2026-10-11 明确允许这些游戏项目使用 AI 重新生成美术资产。本授权适用于 G1–G8 和游戏馆共享界面，可用于新建或替换角色立绘、角色动作、场景、道具、卡面、证据图、UI 装饰、特效与纪念插画。

现有素材是可选参考，不是必须沿用的限制。各游戏可采用适合玩法的独立画风，例如便利店的柔和插画、推理的叙事场景、格斗的侧视动画；保持角色身份可辨识和该游戏内部一致即可。

后续 agent 在已分配游戏任务中可直接安排 AI 美术生成，无需再就“是否允许重新生成”重复确认。本轮是计划更新，不启动生图。此授权不自动扩展为新购买付费套餐、声音克隆、音乐生成或生产部署。

## 制作顺序

1. 列资产需求表：assetId、用途、尺寸/比例、透明要求、动作/帧数、角色 ID、优先级、来源和验收标准。
2. 确定一页视觉规范：色板、视角、轮廓、光照、角色比例和 UI 对比度；先做一个角色、一处场景及一个 UI/特效样本。
3. 放入真实游戏画面验证清晰度、缩放、触屏遮挡和加载成本。独立美图好看不等于适合游戏。
4. 样本达到规则与显示要求后，按当前可玩切片扩充资产，避免一次生成全部角色却无法接入。
5. 导入、优化与版本化；检查运行时路径和透明边缘，记录最终资源与源稿对应关系。

优先使用当前可用且适合任务的图片生成能力，遵守工具与相应 skill 的操作要求；不可用时保留占位资源与明确缺口，不把占位标成最终完成。

## 技术与来源记录

- 建议运行时目录 `assets/game-library/<gameId>/`；源稿、生成中间件和预览存于 `out/game-library-art/<gameId>/`，部署排除规则由集成负责人核实。
- manifest 记录稳定 assetId、相对路径、版本、像素尺寸、用途、关联角色、生成工具/模型（工具有返回时）、提示词或配方文件路径、参考素材来源和后处理步骤。不编造模型元数据。
- 有参考图时保留来源和使用范围记录。AI 生成不自动赋予对所有第三方角色、商标或素材的使用权；不要把生成内容称为主播官方美术。
- 透明素材按真实透明背景输出；游戏文字、关键线索和按钮标签由 UI 渲染，避免依赖生成图内文字的准确性。
- 序列动画固定画布与锚点；碰撞框、热点、音符判定和卡牌规则不由图像像素推导。剧情关键证据必须有可读取文本。
- 新资产使用版本化路径或清单，替换前保留可回退版本；不覆盖其他游戏仍依赖的旧资源。

## 按游戏的重点

| 游戏 | 可重新生成的重点 | 必须检查 |
|---|---|---|
| G1 经营 | 成员立绘、直播间、节目与设备图标 | 状态与经济 UI 可读，人物跨事件一致 |
| G2 便利店 | 店内昼夜/天气场景、人物表情、商品与纪念物 | 对话留白、商品辨识、同场景透视一致 |
| G3 派对 | 舞台、角色头像/短动作、道具与颁奖 | 图形可快速区分，不能只靠颜色 |
| G4 合作解谜 | 控制室、设备面板、故障与修复特效 | 符号稳定可描述，不烘焙答案或误导线索 |
| G5 卡牌 | 卡面、危机形象、背景与技能特效 | 卡面缩小可辨，费用与规则文本独立 |
| G6 推理 | 场景、证据图、表情、结尾图 | 热点与证据事实匹配，关键线索有文本替代 |
| G7 音游 | 舞台、角色演出、界面与结算插画 | 判定线不遮挡，特效可减弱，音符对比度稳定 |
| G8 格斗 | 侧视角色动作、舞台、命中特效与头像 | 动作连续、锚点一致、轮廓清楚、命中帧匹配 |

## 美术交付检查点

每个游戏任务的“表现/内容完成”必须附资产清单、来源记录、游戏内截图与未完成项。动作类另附播放预览。检查透明边缘、裁切、尺寸、加载失败回退、手机显示和资源体积；未验证授权或质量的内容标记为占位/待确认。

预算使用以已可用工具和用户既有授权为边界，先小批验证再扩量；不以消耗 token 或生成数量作为完成标准。
