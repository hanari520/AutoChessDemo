# 虚拟主播游戏馆 · 计划书索引

日期：2026-10-11。状态：首款 G1 demo 已实现并通过自动化验证，真人试玩待验收；其他作品按计划开发。用户确认独立保存于 `specs/game-library/`，不替换原有八人联机计划。

目标：把现有 demo 扩展成共享虚拟主播主题的多类型游戏馆。六款以单人为主的游戏、两款多人游戏，各自拥有完整玩法；共享收藏与展示是附加层，不能成为单人开玩的门槛。

当前正式入口：[星夜游戏馆](https://autochess.hanari520.cn/)，已接入 7 个现有游戏入口。大厅重设计与上线记录见 [大厅报告](implementation/HALL-report.md)。本地试玩：`http://127.0.0.1:8086/`（需要本地服务器）。见 [G1 交付报告](implementation/G1-report.md) 与 [共享基础报告](implementation/platform-report.md)。

最新开发交接：[G2/P06 暂停交接（2026-10-11）](implementation/HANDOFF-2026-10-11-G2.md)。G2 目前是本地未验收草稿，用户最新要求只保留岁己与栞栞，本轮未部署。

## 内容与使用边界

- 这些是原创设计提案；时长、内容量、数值均是待试玩验证的设计目标，不是已经实现的能力。
- 原策划轮仅编写计划；用户随后已授权实施 demo 和 AI 美术。当前实施范围及未验收项以交付报告和任务清单为准；当前 G1 与统一大厅已上线，其他七款新作仍未实现。
- 用户已允许所有游戏与共享界面使用 AI 新建或替换美术资产；不要求沿用现有立绘。按 AI 美术方案先验证样本再扩量。
- 八款计划均含体验、规则、MVP、后续扩展、技术边界、任务与验收。共享任务统一在任务清单维护，避免多份勾选状态冲突。
- 现有自走棋、异步竞技场、幸存者和 RPG 作为既有游戏接入；不把未核实或已下线入口宣称为可玩。
- 全部角色剧情使用架空企划语境。角色、图片、音乐和其他素材的来源与可用范围逐项记录；不得把虚构剧情描述成真实经历。
