# G5《弹幕地下城》计划书

## 定位

单人卡牌构筑冒险，一次直播化作一条有分支的地下城路线。无需联网，每局目标 15–25 分钟，节点之间与玩家回合起点可继续存档。

“直播”影响规则：节目牌带动气氛，设备牌维持资源，观众反应牌利用连锁；危机是卡顿、冷场和设备异常。不是给普通攻击换名字。

## 首版战斗规则

- 玩家稳定度 30，降到 0 本局结束；每回合行动能量 3、抽 5 张，未打出的牌回合结束弃掉。抽牌堆空时洗入弃牌堆，洗牌使用局内种子。
- 危机拥有压力值与公开意图；节目牌降低压力，压力归零获胜。玩家先行动，结束回合后危机执行意图，再开始下一回合。
- 气氛 0–10：部分牌增加气氛，部分消耗气氛强化效果；每回合结束自然减少 2，地板为 0。护场值吸收本回合稳定度损失，下回合开始清空。
- 设备牌打出后持续本场，有清楚的触发时点；同名设备最多一件，重复牌不能无限叠加。状态只有气氛、护场、卡顿、灵感四类起步。
- 战斗胜利给三选一卡牌或跳过，局内货币可在休整点用于删牌、升级或恢复。不开局外战斗属性成长。
- 首版路径为 6 层：普通危机 → 二选一事件/危机 → 休整 → 精英/普通危机 → 事件 → 首领。分支路线最后汇合，任一路径均保证可完成。

初始数值为候选值。G5-01 必须定义牌效果结算顺序、抽牌/弃牌触发上限及同回合胜负同时发生时的规则，写入规则文档。建议每次动作原子结算后先判断玩家存活，再判断危机清除，避免 UI 自行决定。

## 三种构筑

1. 慢热演出：积累气氛，以高气氛牌收尾；前期要用护场稳住。
2. 接梗连锁：不同类型牌连续打出获得奖励；单牌弱，但节奏灵活。
3. 设备运营：先投入能量布置设备，后续获得抽牌或稳定收益。

三名起始角色各有一张标志牌和一个简单被动；所有角色开局可选。首版 24 张牌（每流派 6 张、通用 6 张）、6 类危机、1 首领、6 事件。每个词条点按可解释。

## 页面、存档与奖励

选角色 → 路线 → 战斗/事件 → 奖励 → 休整 → 首领 → 战报。手机手牌用点选预览再点目标，不能依赖拖拽精度。保留本回合行动日志。

保存种子、随机状态、牌堆顺序、角色资源、路线与结算标识。回合起点存档恢复后不得换牌；节点奖励已生成后读档不能重抽。解锁内容为卡牌图鉴、挑战徽章与纪念海报。

## MVP 与后续

首版完整六层路线和三流派；后续增加路线章节、横向角色机制、挑战种子、分享牌组。首版不做 PVP、排行榜、卡牌付费包、跨游戏数值奖励或无限生成卡牌。

## 技术与任务

目录 `games/danmaku-deck/`；卡牌以有限效果类型配置，规则核返回事件序列供 UI 播放。所有卡牌描述由相同参数插值或校验，避免说明与效果脱节。

G5-01 单场战斗 → G5-02 路线与构筑 → G5-03 存档奖励 → G5-04 全内容与试玩。

## 验收

- 洗牌、空牌堆、0 费连锁、满气氛、重复设备、同动作胜负边界都有规则测试；设每动作事件上限并将异常视为错误，不静默截断正常效果。
- 三种固定合法牌组均可用可记录的操作序列击败首领；这一测试只证明可行，不声称平衡。
- 固定种子与操作重放一致；动画跳过/加速不改变状态，双击牌不重复扣能量。
- 玩家在第一战能读出危机下一步行动、当前能量与防御效果；手机可查看牌面而不误出牌。

若稳定重复同一个动作就能赢，先修资源约束与敌方意图。若只能靠随机抽中某张牌过关，降低单卡依赖或提供牌组调整路径。
