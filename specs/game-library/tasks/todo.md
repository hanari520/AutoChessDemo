# 游戏馆执行任务清单

状态：2026-10-11 已完成 P01–P05 与 G1-01–G1-03；G1-04 自动化及表现已完成，真人试玩待验收。本轮已开始 G2 与 P06，用户额度暂停；最终验收未完成，详细状态见 [G2/P06 交接](../implementation/HANDOFF-2026-10-11-G2.md)。任务的概念范围见总计划和对应游戏计划；本文件为唯一勾选清单。

## 执行规则

- 一个任务一次只交给一个负责人；每个提交切片以 1–5 个文件为目标。范围超过一次聚焦会话时，先拆成带同前缀的子任务，保留原任务未完成状态。
- 初始游戏目录文件建议 core.mjs、content.json、index.html、app.mjs、style.css、core.test.mjs；按任务实际需要分批创建，不要求一次修改全部。
- 所有测试命令必须由实施者根据实际文件提供并执行，不把本文拟定路径当成现成命令。
- 每款 01–02 完成后为核心检查点，03–04 为交付检查点。完成任务不代表自动获得上线授权。
- 游戏 01/02 可在共享系统未完成时用内存适配器独立验证。03 明确依赖 P04/P05；不得伪造云端保存或奖励已接通。
- 多人客户端与该游戏服务端目录由同一负责人协调；公共房间代码仅平台负责人改。所有角色遵守项目 AGENTS 模型范围与升级规则。
