## 0. 一句话结论

**巡演企划管「演出」，经典模式管「赛事」。**

两边共享同一个世界观（星域事务所 + 50 位主播 + 羁绊 = 共演共鸣），但**各自使用一套不交叉的语汇**：
- 巡演企划 = 事务所的**外景长篇**，用「演出 / 舞台 / 登台 / 谢幕 / 退场者 / 静默」说话；
- 经典模式 = 事务所的**常设棋战赛**，用「赛程 / 阵容 / 守关 / 排名 / 晋级」说话。

这样做的收益：玩家不会把重复可玩的经典模式误当成剧情模式而失望；主线也不会因为两处都在喊「舞台」而失重。

## 1. 为什么必须分家（现状事实，不是假想）

盘点结论（依据 `index.html` / `tools/solo-host.js` / `tools/daily-curses.js`）：

| 现状 | 事实 | 风险 |
| --- | --- | --- |
| 经典模式**已经在用** | 「偶像」职业名（`index.html:1475`）、「应援充能」羁绊效果（`:1475`）、「开局应援」招募（`:2097`）、章节目标名「新人舞台」（`:2267`） | 「应援」「偶像」是棋子/机制层词，**应当共享**，不必清理 |
| 经典模式**完全没用** | 「演出 / 舞台 / 公演 / 巡演 / 登台 / 谢幕 / 退场者 / 静默」——玩家可见层**只出现在 `expedition`** | 这是**既有优势**：分家的地基已经在了，本文只是把它变成显式规范并补上经典模式**自己的正面身份** |
| 现状问题 1 | 经典模式的文案**没有正面身份**——它只是"没有演出的那一半"，读起来像机制说明板，粉丝向味道淡 | 粉丝优先定位下，玩家最常玩的模式反而最没有性格 |
| 现状问题 2 | 产品名不统一：首页/标题是「**星域棋战**」（`index.html:12,1202`、`manifest.json:2`），战绩分享卡画布是「**虚拟棋战**」（`index.html:7009,7068,7077,7083`） | 分享卡是传播物料，名字错等于每次传播都在稀释品牌 |

> 「新人舞台」（`index.html:2267`）这个名字**保留**：它是章节挑战名，属于**收集层**，且已带「舞台」意象却不占分家禁区——详见 §2.3 的例外说明。

## 3. 经典模式声音定位（Voice & Frame）

### 3.1 框架：星域事务所 · 常设赛（STAR LEAGUE）

**一句话**：制作人带队，参加事务所排的常设棋战赛——一局一局打上去，靠阵容和节奏把名次打高。

**为什么是「赛事」而不是别的**（四条依据，不是随口取）：

1. **与「巡演」正交**：赛事 vs 巡演，零语汇冲突，分家成本最低。
2. **现有机制全都有归宿**：排行榜、名次、八人竞技的淘汰制、每日挑战的"全体同种子比谁推得远"——这些**本来就是赛制**，用赛事框架解释是零成本的。
3. **粉丝向**：偶像打歌榜 / 体育运动会 / 排名战，对粉丝是熟面孔；「看自家推的名次」是天然的低成本留存钩子（对齐 `level-design-plan-2026-09-25.md` §7）。
4. **与产品名咬合**：游戏叫「星域**棋战**」。玩家打经典模式时，打的就是「星域棋战」本身；巡演企划是它的长篇叙事外挂。

### 3.2 声音支柱

| 维度 | 规定 |
| --- | --- |
| **玩家身份** | 制作人（P）。与巡演**一致**（身份连续性必须保持，否则玩家会以为换了游戏） |
| **基调** | 务实、轻快、有一点综艺感。**机制优先，情绪点到为止** |
| **句长节奏** | 单屏 ≤ 2 行；不写抒情长句、不写感叹式排比 |
| **口吻** | 像"带队教练 + 场记"：说清楚要做什么，不解释心情 |
| **情绪分工** | **经典模式负责「爽」和「想再来一局」；巡演企划负责「被戳到」。** 两边不要抢 |
| **禁用** | 见 §2.2；另外不写死亡、不写背叛、不写恋爱（沿用 `world-bible.md` §0.1 合规红线） |
| **呈现方式** | **纯文字，零新增配音**：经典模式全部文案以界面文字呈现——**不做人声配音（VO）、不做语音合成、不新增任何音频文件**；音效只沿用现有 `SFX_DEF`（`index.html:2905-2968`） |

### 3.3 「他们绝不会说的话」（负面范本）

| ❌ 不会出现 | ✅ 会说 |
| --- | --- |
| 「今晚的舞台属于我们！」 | 「阵容调好了，开打。」 |
| 「观众在等我们。」 | 「名次自己会说话。」 |
| 「用这场演出证明自己！」 | 「这局先稳住前排，下局再冲。」 |
| 「我们一定会赢！」 | 「打完看复盘。」 |

> 判据：**任何把经典模式的一场对局说成「演出」的句子，一律重写。** 经典模式里没有观众席，只有对手和排名。
