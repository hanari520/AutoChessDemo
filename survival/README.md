# 星域幸存者内容扩展

入口：`http://127.0.0.1:8081/survival.html`。保持 Phaser 3.90 的原有移动、自动攻击、六武器、20 波和商店循环。

## 内容来源与边界

- 角色及第二职业 / 阵营：本项目 `index.html` 的 `UNITS`。
- 50 个技能名称、模式和参数：本项目 `COMBAT_KITS`，由 `tools/export-survival-roster.cjs` 输出 `classic-kits.js`；生存描述与规则由 `content.js` 和 `skills.js` 适配。
- 动作帧：用户提供的 `F:/autochess-godot`，保持原项目只读，仍按出战阵容加载六套动作。
- 武器 / 技能图像：本项目既有 `assets/fx`；没有复制《土豆兄弟》的美术、声音、代码或存档。
- 参考《土豆兄弟》的六武器、职业特性、武器分类、成长与商店组合设计。官方概述：[Brotato Steam](https://store.steampowered.com/app/1942280/Brotato/)。本机 PCK 仅以 `tools/inspect-brotato-reference.py` 只读解析，校验选定文本的 MD5，输出路径、字段名和设计观察，不提取游戏资产、不执行游戏脚本；摘要在 `out/survival/content/brotato-reference.json`。

这是生存玩法的再设计，不是原版逐项复刻。生存敌人没有法力与治疗系统，所以经典削蓝 / 沉默转为打断射击；护盾破坏转为易伤；斩影不强制移动玩家；伙伴不可受伤，保护 / 链接转为主角护盾。经典嘲讽、反射弹道、敌方治疗封锁、相位穿越等没有逐项移植，界面只显示已实现效果。

## 专属技能与成长

47 个主动技能按角色参数改造成屏障、治疗、支援、单点、斩影、多段、冲击、连锁、持续区域或广域术式。自动施放间隔默认 6.5 秒，支援 / 护盾 / 治疗默认 8 秒；回转降低间隔。主角技能 I-V 阶，每阶增加基础强度；伙伴固定 I 阶与 45% 强度。相同技能类别共用执行器，目标选择、倍率、多段、控制、流血和汲取由各自经典参数决定，并非 50 套独立引擎。

三名被动角色通过主角武器命中触发，不定时假施法：轴伊每 5 次命中给目标易伤；雨纪每 8 次命中蓄积一次闪避，最多两次；又一每 6 次命中治疗，半血以下加护盾。技能强度 / 阶级提高被动触发效率。汲取按实际扣除的敌人生命计算，不用过量伤害刷治疗；技能 / 流血 / 弹射不会递归触发武器效果。

成长新增技能强度、回转、暴击、闪避、汲取、余波持续时间、治疗量和护盾量。暴击上限 75%，倍率 175%；闪避上限 45%；通用汲取上限 20%。护盾上限为最大生命的 65%，5 秒无补充后消失。首领控制时间为普通敌人的 25%。持续区域最多 12 个，按模拟时钟更新，暂停不会偷跑。
