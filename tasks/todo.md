# 八人联机模式任务清单

- [ ] 1. 冻结联机规则、席位信息可见性和消息协议；验收：规则版本与合法操作表明确。
- [ ] 2. 抽取并验证确定性的卡池、经济和操作规则；验收：同种子同操作得到同摘要，单机回归通过。
- [ ] 3. 抽取并验证权威战斗结算；验收：固定阵容的重复结算一致，性能预算有测量值。
- [ ] 4. 打通两席房间的加入、购买、锁定、结算；验收：两浏览器看到一致结果，非法操作被拒绝。
- [ ] 检查点 A：两席完整纵向对局可复现，服务器状态为唯一真相。
- [ ] 5. 扩展八席配对、共享卡池、淘汰和名次；验收：八客户端可完成一局，无超卖。
- [ ] 6. 实现阶段计时、掉线重连、托管和对象重启恢复；验收：无重复结算，重连视图正确。
- [ ] 检查点 B：八席故障注入和长局测试通过。
- [ ] 7. 实现独立联机入口、大厅、对局、观战、结算界面；验收：桌面与手机主路径可用，单机未回归。
- [ ] 8. 完成并发、恶意输入、信息隔离、性能和联机规则版本验收；验收：无负值、超卖和其他席位隐藏信息泄露。
- [ ] 检查点 C：八席简化战斗联机原型完成，界面及文档明确标注与正式规则的差异。
- [ ] 9. 抽取可在服务端运行的完整战斗核心；验收：50 技能、装备、羁绊和真实站位均由权威引擎结算。
- [ ] 10. 固定种子镜像对照与性能测试；验收：战斗事件、伤害、胜负对照一致，八席并发负载符合预算。
- [ ] 11. 邀请制灰度与监测；验收：可独立关闭联机入口，单机持续可玩。
